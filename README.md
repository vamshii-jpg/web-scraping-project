# News Headlines Web Scraper

## Description
This Python project scrapes the top news headlines from a specified news website and saves them to a text file.

## Technologies
- Python 3.x
- requests library
- BeautifulSoup library

## How to run
1. Clone or download the repo.
2. Install dependencies: pip install requests beautifulsoup4
3. Replace the URL in scrape_news.py with your target news website.
4. Run the script: python scrape_news.py
5. The headlines will be saved in headlines.txt

## Notes
- Update the HTML tag selector in the script as needed based on the target website's HTML structure.
- Use responsibly respecting the site's terms of service.
